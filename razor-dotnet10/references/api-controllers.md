# API Controllers — Reference

## Controller Structure

```csharp
[ApiController]                         // ← required: enables auto-validation, binding inference
[Route("api/v{version:apiVersion}/[controller]")]
[Produces("application/json")]
[Authorize(AuthenticationSchemes = JwtBearerDefaults.AuthenticationScheme)]
public class ProductsController(IProductService service) : ControllerBase
{
    // ControllerBase — no View() support (correct for APIs)
    // Controller    — adds View() support (for MVC with views)
}
```

## HTTP Methods & Return Types

```csharp
[HttpGet]                               // GET /api/products
[HttpGet("{id:int}")]                   // GET /api/products/5
[HttpGet("{id:int}/details")]           // GET /api/products/5/details
[HttpPost]                              // POST /api/products
[HttpPut("{id:int}")]                   // PUT /api/products/5
[HttpPatch("{id:int}")]                 // PATCH /api/products/5
[HttpDelete("{id:int}")]               // DELETE /api/products/5
```

```csharp
// ✅ Typed IActionResult with ProducesResponseType
[HttpGet("{id:int}")]
[ProducesResponseType<ProductDto>(StatusCodes.Status200OK)]
[ProducesResponseType(StatusCodes.Status404NotFound)]
public async Task<IActionResult> GetById(int id, CancellationToken ct)
{
    var item = await _service.GetByIdAsync(id, ct);
    return item is null ? NotFound() : Ok(item);
}

// ✅ ActionResult<T> — slightly shorter, same result
[HttpGet("{id:int}")]
public async Task<ActionResult<ProductDto>> GetById(int id, CancellationToken ct)
{
    var item = await _service.GetByIdAsync(id, ct);
    return item is null ? NotFound() : item;  // implicit Ok()
}
```

## Standard Response Helpers

```csharp
Ok(value)                   // 200
Created(uri, value)         // 201
CreatedAtAction(...)        // 201 with Location header
NoContent()                 // 204
BadRequest()                // 400
BadRequest(ModelState)      // 400 with validation details
Unauthorized()              // 401
Forbid()                    // 403
NotFound()                  // 404
Conflict()                  // 409
UnprocessableEntity(...)    // 422
Problem(...)                // RFC 7807 ProblemDetails
```

## ProblemDetails (RFC 7807)

```csharp
// Custom problem response
return Problem(
    title: "Product not available",
    detail: $"Product {id} is out of stock.",
    statusCode: StatusCodes.Status409Conflict,
    instance: HttpContext.Request.Path);

// Validation problem (auto-generated by [ApiController] on 400)
// {
//   "type": "https://tools.ietf.org/html/rfc7807",
//   "title": "One or more validation errors occurred.",
//   "status": 400,
//   "errors": { "Name": ["The Name field is required."] }
// }
```

## Grouping with MapGroup / Route Groups

```csharp
// In Program.cs — prefix all controller routes
app.MapControllers(); // reads [Route] attributes

// ── Or use Minimal API groups alongside controllers ──
var api = app.MapGroup("/api").RequireAuthorization();
var v1 = api.MapGroup("/v1");
```

## Filters

```csharp
// Action filter — logging, validation
public class ValidateModelFilter : IActionFilter
{
    public void OnActionExecuting(ActionExecutingContext context)
    {
        if (!context.ModelState.IsValid)
            context.Result = new BadRequestObjectResult(context.ModelState);
    }
    public void OnActionExecuted(ActionExecutedContext context) { }
}

// Register globally
builder.Services.AddControllers(o =>
    o.Filters.Add<ValidateModelFilter>());

// Or per controller/action
[ServiceFilter(typeof(ValidateModelFilter))]
public class ProductsController : ControllerBase { }
```

## Binding Sources

```csharp
// [ApiController] infers these automatically:
// Complex type from body → [FromBody]
// Simple type from route → [FromRoute]
// Simple type from query → [FromQuery]

// Explicit when needed:
public IActionResult Upload(
    [FromForm] IFormFile file,       // multipart/form-data
    [FromHeader(Name = "X-Api-Key")] string apiKey,
    [FromQuery] int page = 1)
{ }
```


## Global Exception Handling

```csharp
// Program.cs — .NET 10 built-in exception handler
app.UseExceptionHandler(exApp =>
{
    exApp.Run(async context =>
    {
        context.Response.StatusCode = StatusCodes.Status500InternalServerError;
        context.Response.ContentType = "application/problem+json";

        var ex = context.Features.Get<IExceptionHandlerFeature>()?.Error;
        var problem = new ProblemDetails
        {
            Title = "An unexpected error occurred.",
            Status = 500,
            Detail = context.RequestServices
                .GetRequiredService<IHostEnvironment>().IsDevelopment()
                ? ex?.Message : null
        };
        await context.Response.WriteAsJsonAsync(problem);
    });
});
```
